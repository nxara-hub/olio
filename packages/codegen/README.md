# @nxara/olio-codegen

Generate TypeScript types from GraphQL SDL: the schema's types and the `Application` contract that types olio's builders, plus typed operations for `@nxara/olio-client`.

```sh
bun add -d @nxara/olio-codegen
bun add graphql@16
```

**[Read the docs](https://olio.nxara.dev/reference/codegen/)**

**For AI agents:** [the docs as one file](https://olio.nxara.dev/llms-full.txt), or the skill: `npx skills add nxara-hub/olio`.

Part of [olio](https://olio.nxara.dev): modular, type-safe GraphQL for TypeScript. MIT licensed.
