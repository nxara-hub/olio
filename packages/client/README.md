# @nxara/olio-client

A typed GraphQL client for olio apps: write operations in `.graphql` files, codegen types them, and call each one as a typed function. `testClient` runs your app in tests.

```sh
bun add @nxara/olio-client graphql@16
```

**[Read the docs](https://olio.nxara.dev/reference/client/)**

**For AI agents:** [the docs as one file](https://olio.nxara.dev/llms-full.txt), or the skill: `npx skills add nxara-hub/olio`.

Part of [olio](https://olio.nxara.dev): modular, type-safe GraphQL for TypeScript. MIT licensed.
